# oneKeyHall 本地 Web 上位机

这是适配本项目磁轴固件的原生网页控制台，当前配套固件为 V2.6.1、配置 V06。入口为 `index.html`，业务代码在 `assets/app.mjs`，串口协议在 `assets/protocol.mjs`，样式在 `assets/hall.css`。不依赖 npm 包，不需要打包。

双击 `start.cmd`，或在本目录执行 `npm start`，然后用桌面 Edge / Chrome 打开 http://127.0.0.1:5173 。需要 Node.js 18 或更新版本。

界面支持两点校准、固定触发 / RT、实时 ADC 和相对行程、两套按键映射、双击、ASCII 文本以及 RGB。首次需完成校准。使用说明、编译及验证范围见 [项目 README](../README.md)，协议见 [HALL_PROTOCOL](../docs/HALL_PROTOCOL.md)。

当前仅保留 oneKeyHall 网页实现；旧原站镜像及 Windows 伴随程序已清理。

运行 `npm test` 可执行当前 55 项 Node 测试，覆盖串口协议、键盘事件、RT、设备设置、线性/灯光、双语、自动应用和恢复出厂设置。测试不连接硬件。

本地服务仅监听 127.0.0.1。端口占用时先检查是否已运行；修改端口可在 PowerShell 执行 `$env:PORT = '5174'` 后再执行 `npm start`。

通过本地 HTTP 或 HTTPS 访问，不要直接使用 `file://` 打开页面。GitHub Pages / Cloudflare Pages 静态托管配置见 [部署说明](../README.md#部署网页)。

## 自动应用与保存

修改有效参数后约 400 ms 自动应用到设备 RAM，不自动写入 DataFlash。点击“保存配置”才会使参数和累计次数断电保留，已移除单独的应用按钮。校准期间暂停自动应用与按键输出，成功采集底部后自动应用校准；随后松开轴体。

“放弃待应用修改”只清除待应用输入或未完成校准，不撤销已经应用的参数。自动应用后关闭网页或串口不会停止设备运行；断电后恢复最后保存的配置。参数写入被固件拒绝时会尝试取消未提交会话；串口超时或断流时关闭连接，不在失同步串口上重试。

## 键盘测试、RT 与 ISP 入口

网页“固件更新 → 进入下载模式”在连接支持命令 99 的设备后启用。点击后确认未保存配置会丢失，再请求进入 ISP；设备关闭 LED，网页收到成功 ACK 后关闭串口。随后使用 CH54x-55x 烧录工具更新固件，网页不会自动烧录，成功 ACK 也不能单独证明 ISP 枚举完成。历史取证流程保留在专门文档中，不作为日常界面的操作前提。

“设备信息 → 打开键盘测试”无需串口连接，显示按下/释放、当前组合键和事件记录，并提供文本测试框。界面参考原站的圆角导航、紫色主色和卡片布局，支持浅色/深色/系统主题。

启用 RT 后，实时行程条增加抬起释放和再次按下参数线。新版固件上报极值，用高亮线指出下一次实际阈值；旧固件显示参考线。未应用的参数标记为预览。相关实现分别在 `assets/keyboard-test.mjs`、`assets/rt-markers.mjs`、`assets/theme.mjs`。

若下载按钮仍为灰色，可查看旁边的固件能力值。当前默认发布的 2.6.1 固件是 0xFF，支持 ISP；设备需先刷入支持该命令的固件再重新连接，网页本身无法升级它。默认固件的历史取证步骤见 [取证说明](../docs/REPRO_CAPTURE.md)。

下载按钮下新增带 UTC 时间的请求记录：用户取消、请求等待、成功 ACK、串口关闭或失败原因。最近 12 条只保存在当前页面内存中，刷新清空，并移除旧版 localStorage 记录。它不证明 ISP 枚举成功，也不能替代断电取证。按钮不会自动打开烧录软件；CH55xDuino 文档提示 BootLoader 可能超时退出：https://github.com/DeqingSun/ch55xduino#driver-for-windows 。

## 设备内线性模式

V2.4.0 起线性功能在设备内通过 USB HID 运行；自动应用后就可以关闭网页和 Node 服务，保存后断电保留，无需安装 .NET 伴随程序。当前网页不再启动旧 native 程序，详见 [线性模式说明](../docs/LINEAR_MODE.md)。

## BootLoader、默认名称和行程灯效

V2.5.0 起提供独立的 BootLoader 版本、40 位芯片序列号和四种行程灯效，见 [协议说明](../docs/HALL_PROTOCOL.md)。BootLoader 无法识别时显示“未识别”；老固件未提供接口时显示“固件未提供”。串口查询失败仍按通信错误处理。应用版本单独查询，不把配置格式或 USB 版本当作 BootLoader 版本。

空名称使用 `oneKeyHall` + 10 位十六进制序列号，自定义名称优先。名称在启动时写入 USB 产品/CDC 接口描述符，保存后需要拔插 USB。四种行程灯效同样在设备内运行，旧版固件禁用相应选项。新字段和提示支持中文/English。

设备改名、双击间隔与校准/灯效用法见 [项目 README](../README.md)。网页兼容 V02–V06 格式磁轴固件，各功能按设备能力和配置格式启用，不支持旧机械轴固件。

项目显示名称和默认输入文本为 oneKeyHall；默认设备名称在该前缀后附加芯片序列号。当前版本变化见 [V2.6.1 说明](../docs/RELEASE_2.6.1.md)。

## 发布最新固件供下载

网页“固件更新”新增“下载最新固件（HEX）”，无需连接设备。把新版 HEX 命名为 `latest.hex`，放进 [firmware 文件夹](firmware/README.md)，覆盖旧文件即可。固定下载地址为 http://127.0.0.1:5173/firmware/latest.hex ，保存名为 `oneKeyHall-latest.hex`。此地址只在本地服务运行时可用，不是公网地址。

当前下载槽提供 V2.6.1 ISP 固件。修改 `server.mjs` 后需重启服务；修改前端后刷新网页；仅替换 HEX 不需重启。本地服务直接返回文件且禁用缓存，编译不自动发布。文件下载与进入设备 ISP 是独立操作。

## 中英文切换

导航栏可选择“中文 / English”，即时切换并记住选择；首次访问按浏览器语言选择（中文语言使用中文，其余使用英语）。触控测试页也提供相同选项，同源标签页会同步选择。无需刷新、重新连接或更新设备固件；当前连接、表单数值、设备名称和自定义输入文本保持不变。

`assets/i18n-catalog.mjs` 保存完整文案的中英对照；`assets/i18n.mjs` 处理动态数值模板、语言存储和显示更新。现有渲染器继续产生中文源文案，显示层只翻译已登记的完整消息和参数模板，不对任意用户字符串做子串替换。按文本节点保存源文案，切换时只更新文本、title、placeholder 和 aria-label，不重建表单或调用串口。新增界面文案时须补充词条/模板及 `tests/i18n.test.mjs` 覆盖。浏览器原生串口选择框等由浏览器自身语言决定。

已有验证覆盖静态文案、动态提示、语言记忆和表单保留；尚未完成完整浏览器视觉验收，详见 [验证报告](../firmware/build/verification.json)。

## V2.6.0 线性操作与指令表

导航中的“串口指令表”打开站点内的 `assets/protocol.html`，提供完整中英文查询页面，不连接设备；当前包含 15 条命令、137 个配置字节及状态/能力/错误码。导航也提供“开源仓库”入口。固件版本仅显示版本号；工作模式选项为“线性模式”。V2.6.0 起支持保存“**双击切换反向**”开关并使用共享双击间隔，实时显示方向，同时统计有效按下后的正常释放。旧固件显示不支持的说明。面积/压力仍需要固定 X/Y，当前光标选项只是鼠标左键，见 [线性模式说明](../docs/LINEAR_MODE.md)。

## 恢复出厂设置

V2.6.1 起支持页面下方的“恢复出厂设置”。确认后清除名称、校准、计数、按键、灯光和线性设置并立即保存，待执行的自动应用会取消。取消确认不会清除表单。完成后重新校准，拔插 USB 后名称恢复为 oneKeyHall 加芯片序列号。旧固件按钮禁用；更新网页不能代替烧录新固件。详见 [2.6.1 说明](../docs/RELEASE_2.6.1.md)。

## 同仓库部署到 GitHub Pages

使用仓库中的 `.github/workflows/pages.yml`，在 Settings → Pages 将 Source 设为 GitHub Actions。提交至 main 后运行该工作流，仅发布网页资源和 `firmware/latest.hex`。详细步骤见 [项目部署说明](../README.md#部署网页)。所有页面使用相对资源路径，支持 `/oneKeyHall/` 项目路径；用户用桌面 Chrome / Edge 打开 HTTPS 网页即可配置本机设备，无需本地 Node 服务。
