# oneKeyHall 2.6.1

新增恢复出厂设置，配置格式继续使用 V06，已有参数无需迁移。

## 使用

1. 烧录 `firmware/build/onekeyhall-ch552-24mhz.hex`，拔插 USB 后连接网页。
2. 在页面下方找到“恢复出厂设置”。按钮要求设备实际版本为 V2.6.1 或更新版本。
3. 阅读确认提示，确认后清除并保存设备配置。
4. 重新完成两点校准并保存；拔插 USB 后，USB 名称恢复为 `oneKeyHall` 加芯片序列号。

重置范围包括名称、校准、计数、按键映射与文本、双击间隔、RT、灯光、线性预设和双击反向开关。KEY1 恢复为空格，默认文本为 `oneKeyHall`，双击间隔为 200 ms。固件、BootLoader 和芯片序列号不变。网页语言与主题属于浏览器设置，不受设备重置影响。

恢复出厂设置立即写入 DataFlash，无需再次点击保存。确认后网页取消待执行的自动应用，避免旧表单覆盖默认配置。失败时断开配置连接并显示原因，重新连接确认设备状态；不会自动重试重置。

## 协议

新增 `{999:15}`，无需开始设置会话。采样进行中拒绝并返回 `[1000,15,1]`；成功写入并校验后返回 `[1000,15,0]`；存储校验失败返回 `[1000,15,5]`。重置会结束已有设置会话，旧备份不能通过命令 14 恢复。输出释放后，设备保持未校准状态。

应用版本回复为 `[1003,2,6,1,1]`，默认 ISP 能力仍为 `0xFF`。网页串口指令表已加入新命令，中英文同步更新。

- Flash：14312 / 14336 字节；应用 XRAM：458 / 758 字节。
- 40 组固件主机测试通过，另含 USB、ROM 和文本输入测试。
- 54 项 Node 测试通过，覆盖确认取消、版本判断、阻止旧参数自动应用、失败传递及双语文案。
- 固件测试验证完整默认值、重启后持久化、采样时拒绝、存储失败、重试及鼠标/触点释放。
