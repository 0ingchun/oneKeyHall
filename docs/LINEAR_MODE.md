# oneKeyHall 设备线性模式（V2.6.1）

本版由 CH552 直接发送 USB HID 鼠标、媒体音量键和单点触屏报告。网页只配置参数和显示行程；配置保存到设备后，关闭网页、断开串口、停止本地网页服务或换电脑均不依赖伴随程序。无需安装 .NET。旧 Windows 伴随程序、桥接 API 和对应测试已移除。

## 使用

1. 烧录 V2.6.1：统一使用 `firmware/build/onekeyhall-ch552-24mhz.hex`，默认支持软件进入 ISP。保留 DataFlash 可迁移旧设置。
2. 运行 `host/start.cmd`，刷新网页。连接后应显示 V2.6.1，配置 V06，能力 0xFF。当前只发布默认支持 ISP 的固件；网页不自动烧录。
3. 确认磁轴已校准，选择“工作模式 → 线性模式”，选择预设和参数；停止修改约 400 ms 后自动应用到 RAM。点击“保存配置”才会断电保留，已无单独的“应用，不保存”按钮。
4. 松开轴体到顶部，等待就绪后按压。可以关闭网页，打开目标应用。
5. 要退出，重新连接网页，切换为直接 KEY1 / KEY2，等待自动应用；进入校准也会暂停所有输出。网页隐藏、断开串口和 F8 不会停止设备模式。

## 预设

| 预设 | 松开 | 压到底 | 中间行程 |
| --- | --- | --- | --- |
| 音量正向 | 估算最低音量 | 估算最高音量 | 媒体音量键追随估算目标 |
| 音量反向 | 估算最高音量 | 估算最低音量 | 反向估算 |
| 滚轮向上 / 下 | 停止 | 1–100 格/秒指定速度 | 累计小数格后输出，近似线性 |
| 当前光标 | 松开左键 | 保持左键 | 按触发点/释放点/RT 判定 |
| 固定位置触摸面积 | 无触点 | 最大面积 | 面积增加，压力固定为最大值 |
| 固定位置触摸压力 | 无触点 | 最大压力 | 压力增加，面积固定为最小值 |
| 固定位置面积与压力 | 无触点 | 两者最大 | 两者同时增加 |

除当前光标点击外，使用磁轴配置的顶部死区，将死区外的相对 ADC 行程重映射到 0–100%。行程是磁场信号的归一化值，不等于精确毫米位移。

从 V2.6.0 起，所有线性预设均累计有效按下后的正常释放，判定使用触发点、释放点或 RT。浅行程未触发、设置暂停和 ADC 故障造成的释放不计数。计数为 16 位，65535 后回到 0，网页约每 0.5 秒读取，显式保存配置才断电保留。

### 当前光标

只发送鼠标左键的按下/释放，X/Y 相对移动为零。鼠标原本在哪里就在哪里点击，不读取屏幕尺寸或当前坐标。按住期间可以用原来的鼠标拖动。这是普通鼠标，没有触摸接触面积和压力。

### 音量

普通 HID 媒体键无法读取系统当前音量滑块。进入音量模式并在顶部就绪后，设备以约 10 ms 按下 / 10 ms 释放发送 100 次音量降低，约 2 秒归零，再通过加减键追随估算目标。USB 忙、其他输出或系统处理可能延长时间。默认假设 50 次按键从 0 到 100%，可配置为 1–100 步。最大追随速率约 50 步/秒，不会瞬间跳到目标。

这是近似映射，不承诺精确对应系统百分比、声压或分贝；不同系统步长、静音处理、系统音量滑块或其他键盘调音量都会影响结果。最低/最高值为估算目标，不是可靠的实际音量限幅。发生偏移时可点“重新同步音量”，松开轴体后重新归零。反向模式松开会升到设定最高值。

### 固定位置触控

设备枚举为单点 HID 触屏，发送接触 ID、Tip、X/Y、宽高、压力、接触数，以及最大接触数特性报告。一次按压对应 DOWN → UPDATE → UP，不是连点器。新触点需超过顶部死区至少 1% 后再建立，回到死区结束。

X/Y 为系统映射显示器宽/高的百分比，存储为 0–32767。设备不查询桌面像素；多屏目标显示器由系统的触屏映射设置决定，不能由固件直接选择。

面积参数单位为屏幕面积的百分比，范围 0.01–2.50%，步长 0.01%。固件先线性插值面积，再开平方得到各轴尺寸；整数开方和 HID 量化会有小误差。宽高分别按各自屏幕轴比例计算，因此不一定是物理像素的正方形。压力为 0–255，是真实触控报告字段，不是实测牛顿力或触控笔压感。

目标系统/应用可能忽略宽高、压力，或把触控转换成鼠标。可打开站点内的 `assets/touch-test.html`，将固定坐标设在测试区域，查看浏览器收到的 `pointerType`、`pressure`、`width`、`height`。PointerEvent 使用 CSS 像素与 0–1 压力，可能经过系统/浏览器转换。

## 双击反向

勾选“**双击切换反向**”后，使用共享的 50–1000 ms 双击间隔（默认 200 ms）。第二次有效按下切换方向，下一对双击切回；两次按下的间隔必须严格小于设置值。音量交换行程方向，滚轮交换上下方向，面积/压力交换大小方向，回到顶部仍停止或抬起触点。当前光标左键预设不支持反向。

双击不延迟或吞掉原有输出，两次有效释放累计两次。开关可保存，临时反向状态不保存；应用参数、重新同步、上电或 USB 状态重置后复位。上表描述未反向时的预设行为。

## 保存与升级

V06 串口配置共 137 字节，DataFlash 内用位打包保存为 127 字节负载 + 1 字节 CRC，总共 128 字节。两组各 30 字节文本和最多 12 个 UTF-16 BMP 字符的 USB 名称不缩短。旧 V02/V03 在原 CRC 校验成功后迁移；若旧工作模式为上位机线性模式 3，迁移成 KEY1，避免升级后自动启动新的输出。新预设默认当前光标点击；重新选择并保存后断电保留。

V04/V05 升到 V06 保留名称、校准、灯效和线性参数，双击反向默认关闭。V2.6.1 恢复出厂设置会清除全部线性参数、计数与校准并立即保存；之后必须重新校准。

设置/校准、ADC 到电源轨或失去校准时释放输出；USB 重置、挂起/恢复和协议切换后释放并等待顶部重新就绪。USB 拔除由系统结束设备输入。普通串口断开不停止已应用的设备模式；未应用的设置会话仍会回退。HID 输出基于主循环和 10 ms 端点调度，并非实测硬实时速率。

## 验证

主机测试覆盖断开 CDC 后运行、按键忙重试、设置/故障释放、滚轮低速小数累计、音量归零/正反向/重新同步、触点生命周期/固定坐标/面积与压力、定时回绕、USB 协议和报告长度、旧格式迁移及完整 EEPROM 往返。默认 ISP 固件已完成 SDCC 编译。未自动烧录，尚需实机验证系统枚举及目标触控应用兼容性。
