# oneKeyHall 2.6.0

> 历史版本说明：本文记录 V2.6.0 引入的功能及当时验证结果。当前发布为 [V2.6.1](RELEASE_2.6.1.md)，固定 HEX 路径与网页下载文件已更新；下文 14 条命令和内存数据仅适用于 V2.6.0。当前网页采用自动应用参数，具体操作见 [项目 README](../README.md)。

固件版本只显示 `V2.6.0`，移除界面的构建类型后缀；工作模式选项简化为“线性模式”。导航新增 [串口指令表](../host/assets/protocol.html)，运行本地服务时地址为 http://127.0.0.1:5173/assets/protocol.html 。页面支持中英文，包含 14 条命令、全部 137 个配置字节、状态、能力位、错误码和调用示例，无设备操作功能。

## 双击反向

在线性模式中勾选“**双击切换反向**”，设置上方双击间隔后应用或保存。默认 200 ms，可设 50–1000 ms。两次有效按下的间隔严格小于设置值才识别为双击；第二次按下时切换，下一对双击切回。方向由网页实时显示。

- 音量：交换所选预设的行程方向。
- 滚轮：上下方向互换，松开仍停止。
- 触控面积/压力：大小映射方向互换；回到顶部仍抬起触点。
- 当前光标左键：普通按钮没有连续方向，不提供此开关。

双击仍产生原预设动作，不延迟等待、不吞单击。开关、间隔和预设可保存；临时方向不保存，重新上电、应用配置、重新同步或 USB 状态复位后恢复所选预设方向。使用触发/释放点或 RT 判断有效按下。

## 累计释放次数

V2.5.0 及之前在线性模式下不计数；从本版起所有线性预设均统计一次有效按下后的正常释放。浅行程没有触发则不计数；设置暂停或 ADC 故障不计数。双击的两次释放算两次。计数为 16 位，65535 后回到 0，网页约每 0.5 秒更新；保存配置才写入 Flash，断电恢复最后保存的次数。

## 当前光标处的面积和压力

本版仍提供固定 X/Y 的真实触控面积/压力，当前光标预设只是鼠标左键。现有 USB 触屏报告使用绝对 X/Y，并不会从电脑读取鼠标位置，不能省略坐标来表示“当前位置”。要使真实触控跟随系统鼠标，需要电脑端程序提供坐标；本次遵循不安装伴随程序的要求，没有假装提供这一功能，界面已明确标注。

依据：[Windows 触屏 HID 要求](https://learn.microsoft.com/en-us/windows-hardware/design/component-guidelines/touchscreen-required-hid-top-level-collections) 和 [主机 GetCursorPos API](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getcursorpos)。这是对当前设备 HID 实现的限制说明，不是把鼠标左键冒充压感输入。

## 烧录与兼容

V2.6.0 曾使用发布路径 `firmware/build/onekeyhall-ch552-24mhz.hex`，默认支持 ISP。该固定路径及网页下载槽现已提供 V2.6.1，不再是 V2.6.0 文件。硬件目标为 CH552、24 MHz、5V。保留 DataFlash 升级可迁移 V04/V05 的名称、校准、灯效和线性预设；擦除 DataFlash 后需重新配置。烧录后拔插 USB 并刷新网页。旧版网页不支持新的状态长度，请使用配套网页。

配置格式 V06，仍为 137 字节 RAM / 128 字节 Flash，config[124] 的 bit 7 保存反向开关；cap bit 7 表示该版本的新能力。详情见 [串口协议](HALL_PROTOCOL.md)。旧版 V02–V05 可在新版网页连接；新选项按能力启用，旧版计数和方向支持会明确说明。

默认 ISP 构建成功：Flash 14296/14336 字节、XRAM 458/758。通过36 组固件模拟测试、USB/ROM/文本输入测试和 当时 50 项 Node 测试（旧 Windows 伴随程序的 3 项测试已移除）。新增测试覆盖双击开关、时间边界、16 位计时回绕和长时间空闲、暂停/故障、反向 HID 报告、计数、持久化、旧配置迁移及协议表覆盖。
