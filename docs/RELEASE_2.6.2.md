# oneKeyHall V2.6.2

工作模式和灯效模式各新增一个关闭选项：

- “按键映射 → 工作模式 → 完全关闭模拟键鼠输出”：与 KEY1、KEY2、单/双击、线性模式并列。释放已有输出，停止键盘、鼠标、音量和触控，继续 ADC 采样、串口读写和有效释放计数。计数使用固定阈值或 RT 判定；浅按、设置暂停、ADC 故障不计数。切回输出模式后需完全松开轴体。
- “RGB 灯效 → 完全关闭灯光”：与固定、呼吸、HUE 渐变和行程灯效并列；选择后全部熄灭，保留颜色、亮度等参数，选择其他灯效重新点亮。

默认 KEY1 模式、灯光开启。修改自动应用到 RAM，显式保存后配置和累计次数断电保留，恢复出厂后重新启用输出与灯光。旧版固件会禁用新增关闭模式并显示升级提示。需同时更新网页与设备固件。

串口配置仍为 V06、137 字节。config[4]=4 选择关闭输出模式；config[7] bit 1 关闭灯光，其余位必须为 0。EEPROM 地址 5 的 bit 5 保存工作模式 bit 2，bit 6 保存灯光关闭位，能力仍为 0xFF。旧配置升级后保持原工作模式。若要降级，先切回模式 0–3 并设 config[7]=0 后保存，或清除 DataFlash 后重新校准；旧固件不能正确解释新的打包字节。

编译占用 Flash 14316/14336 字节，应用 XRAM 454/758 字节；详见 `firmware/build/memory-usage.txt`。精简线性状态检查及灯效冗余初始化，静态灯光在参数改变后立即更新；相同 LED 数据不重复发送，保留原有颜色整数计算。

验证：CH552 24 MHz 目标编译成功；43 组固件主机场景、ROM/USB/HID/文本测试和 60 项 Node 测试通过。新增验证覆盖关闭输出模式的固定/RT 释放计数及无 HID 输出、故障和设置暂停排除、计数持久化、持有输入释放、重新就绪、全部灯效关闭、命令 2、配置持久化、拒绝回退和恢复出厂。未刷写或进行本版实机验收。
