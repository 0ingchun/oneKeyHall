## 实机验收建议

首次发布至少确认两点校准、保存后断电恢复、按键与 RT、双击间隔、设备名称重插生效、行程灯效和累计次数。线性模式分别确认音量、滚轮、固定坐标触控面积/压力；触控效果取决于目标系统和应用。

恢复出厂会清除配置；ISP 会断开应用串口。这两项应在已保存需要保留的数据后单独验证，并以设备实际行为、烧录工具识别结果为准。历史 ISP 异常记录及限制见 [ISP 排查记录](ISP_INCIDENT.md)。
